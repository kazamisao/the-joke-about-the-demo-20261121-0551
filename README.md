A one-line joke about working beside AI coding agents: when the demo crashes, the agent rolls back — not the code, just the chat, to the moment the developer said "yeah, go ahead." `main.py` (Python 3.13, stdlib only, no network) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, deterministically, byte-identical on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 -P -s main.py
```
